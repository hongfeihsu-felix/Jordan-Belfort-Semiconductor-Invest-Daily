🏢 细分领域动态

存储 - HBM：SK海力士万亿俱乐部，三星追赶加速

事件： SK海力士于5月27日市值突破$1万亿，成为继NVIDIA、TSMC、三星、美光之后第五家进入万亿俱乐部的半导体公司（也是首家纯存储企业）。股价24个月累计涨幅~900%，YTD涨幅~250%。Q1营业利润率72%超越英伟达的65%毛利率——存储正从价格接受者变成价格定义者。

HBM4竞争格局： SK海力士维持对NVIDIA Rubin平台约70%的HBM4供应，已完成HBM4开发（功耗降低40%，数据传输率10 Gbps），HBM4E样品计划2026H2出货，2027年量产。三星HBM4已通过NVIDIA/AMD最终认证测试，6月起有望全面量产出货。美光HBM4用成熟1β制程+自研base die，但对下一代HBM4E做出重大战略转向——核心DRAM迁移至1γ制程（首次使用EUV），base die外包给TSMC代工。

三星重大战略突破：

1. 三星投资Anthropic获独家ASIC代工机会——若全面量产，单笔合同规模可达$200亿+（超特斯拉$165亿的AI6自动驾驶芯片），涵盖三星HW/S5/S6韩国产线及德州Taylor新厂

2. 三星已经开始向大客户提供12层HBM4E样品，引脚速度14Gbps（可扩展至16Gbps），带宽达3.6 TB/s，HBM4E产品线覆盖32GB/48GB/64GB

3. 三星获英伟达Grok3 LPU（推理语言处理器）4nm代工订单

4. 三星Tucson工厂获苹果下一代iPhone CIS图像传感器订单

三星18天大罢工风险： 工会于5月29日起发起罢工，可能影响短期内HBM4量产节奏，部分订单可能阶段性回流SK海力士。

竞争影响： HBM格局正从"SK海力士一骑绝尘"向"SK海力士领跑+三星紧追"的双寡头演进。三星一旦在HBM4/NVIDIA Rubin供应链中站稳，SK海力士HBM市占率可能从目前62%压缩至50-60%。但短期罢工风险+存储全品类涨价环境使两大厂均受益。美光HBM4E外包base die给TSMC说明后进者面临更高的技术和资本壁垒。

存储 - 结构性改变：LTA化重构估值框架

事件： 据MK报道，三大存储厂与超大规模客户之间的LTA（长期供货协议）正在根本性地改变存储器商业模式，从传统的"先产后卖"转向"订单制生产"（类似代工业务）。DDR5中60-70%的产能已通过多年合约锁定，2027年预计20-30% DRAM和~20% NAND将转为LTA模式。合约通常采用"3年固定定价+2年续约"或"2年固定+3年续约"结构，部分附带预付款锁定产能分配。

UBS三倍上调美光目标价： Timothy Arcuri将目标价从$535上调至$1,625（华尔街最高），认为"AI驱动的结构性变化已改变整个存储产业"。核心逻辑：LTA提供多年盈利能见度，部分固定价格合约取代波动性现货定价，存储器应该从周期性估值转向基础设施式估值（"normal multiple"）。

竞争影响： 三大存储厂（三星38% / SK海力士29% / 美光22% DRAM市占）全部受益于LTA化。花旗预测三星/SK海力士HBM均价Q4环比再涨~30%，HBM4合同将更充分反映近期DRAM暴涨。Morningstar对三大厂均给出"估值过高"评级，认为存储没有经济护城河。Standard Chartered建议投资者在韩国股票上获利了结，认为"乐观情绪高峰已经不远"。

代工/先进封装：TSMC涨价大潮 + CoWoS是最大瓶颈

TSMC 3nm涨价5-15%： 据Business Korea报道，TSMC计划2026H2将3nm代工价格上涨5-15%，2nm较3nm已上涨50%。1.6nm（A16）单wafer报价达$45,000。台媒报道2027年可能再涨5-10%。

三星代工受益： TSMC涨价正推动大客户加速"多重代工策略"，三星2nm良率已升至~60%（业内认为>60%即可量产），三星代工Q3亏损收窄至₩790亿（vs Q2的₩3,880亿），Q4有望"扭亏为盈"，2027年非存储业务营业利润目标超₩2万亿（~$15亿）。

CoWoS高级封装：TSMC产能6倍扩张仍供不应求

TSMC CoWoS月产能从2024年末~35,000片扩张至2026年末目标120,000-140,000片
NVIDIA预订了2026-2027年60%以上CoWoS产能，仅2026年预订量达~595,000片（其中CoWoS-L ~510,000片用于Rubin）
OSAT外包加单：ASE 2026年资本支出$70亿（+27% YoY），CoWoS级产能扩至25,000片/月，交期延长至12-18个月
黄仁勳5月23日飞抵台北与魏哲家会谈，核心议题即为Vera Rubin的CoWoS产能分配

新IPO/投资： 中国DRAM厂CXMT（长鑫存储）传准备IPO；IBM与美国商务部宣布投资$10亿建设美国首家量子代工厂"Anderon"（CHIPS法案资助）。

竞争影响： TSMC涨价周期利好三星代工获取次选订单，但出货量不足以短期内撼动TSMC主导地位。CoWoS产能紧缺使有CoWoS-L认证的OSAT（ASE/Amkor/JCET）溢价能力上升，交期12-18个月意味着2026H2所有AI芯片出货由CoWoS产能确定天花板。

AI芯片/基础设施：黄仁勳台北行——Rubin是"台湾史上最大产品发布"

NVDA FY27Q1财报： 营收$816亿（+85% YoY），数据中芯$752亿（占比90%），指引Q2 ~$910亿。董事会批准增发$800亿回购，季度股息从$0.01提升至$0.25。

Vera Rubin平台（GTC Taipei 6月1日主题演讲核心）：

六芯片系统：Vera CPU + Rubin GPU + NVLink 6 Switch + ConnectX-9 SuperNIC + BlueField-4 DPU + Spectrum-X Switch
每个NVL72机架：36个Vera CPU + 72个Rubin GPU，近200万个零件，150家台湾供应商参与
性能宣称：训练性能3.5倍、推理性能5倍于Blackwell，推理成本降至1/7
无缆线/无风扇模组化设计，每个模组组装从2小时缩短至5分钟
获COMPUTEX 2026金奖+可持续科技特别奖

NVDA供应集中度风险： 亚洲供应商已占NVDA生产成本的~90%（一年前~65%），TSMC 3nm产能接近上限，NVDA已预订2026年全年服务器整厂产能。若Vera Rubin H2 2026出货正常、CoWoS扩张达标，供应集中风险可控；若任何一个环节延期，将大幅扰动市场预期。

定制ASIC加速追赶： TrendForce预测2026年定制ASIC芯片出货增长44.6%，超过NVIDIA GPU的16.1%——ASIC首次增速超过通用GPU。NVIDIA $1万亿订单管道面临ASIC替代风险（2028年时间框架）。

竞争影响： AI芯片三重瓶颈（HBM→NVDA需求→CoWoS产能）均绑在台湾单一地理节点。黄仁勳亲自飞台锁定产能说明NVDA自身极为重视供应风险。Custom ASIC增速超越GPU是结构性信号——Google TPU/Marvell/Anthropic/Samsung ASIC均在改变AI芯片供需格局。

手机SoC：存储涨价反向挤压，SoC厂被动砍单

更新： 联发科与高通削减4/3nm投片10-15%已获多方确认。三星HBM4量产启动+存储全品类涨价，手机BOM成本持续上行。2026年智能手机出货预期持续下调至11.2亿部（-12.9% YoY，历史最大降幅）。

高通动态： 骁龙8 Elite Gen 5（3nm N3E）保持三星/小米/OPPO旗舰机型定价权。NVIDIA N1X SoC泄露（20核CPU+6,144 CUDA核心，45-80W功耗）即将在COMPUTEX发布——高通首次在Windows on Arm市场面临NVDA实质性竞争。

联发科动态： Dimensity 8500（4nm）在OPPO Reno15/Realme 16 Pro+出货面临下修风险。中国OEM（小米/OPPO/vivo）表达强烈价格谈判意愿。

NVIDIA进军WoA： N1X（20核CPU, 6,144 CUDA，45-80W）/ N1（12核CPU, 2,560 CUDA，18-45W），COMPUTEX 2026将正式发布，Windows on Arm生态从高通独占变为高通+NVDA双轨。

竞争影响： 手机SoC全面进入"存储涨价重压+需求萎缩+竞争加剧"三杀格局。高通高端旗舰定价权最强，但面临NVDA WoA新竞争；联发科中端市场受中国OEM价格谈判挤压最直接，P/E可能进一步压缩至14x以下；紫光展锐入门4G市场份额受益，但成本优势同样收窄。

🔗 传导链追踪

链一：存储涨价传导链（当前：上行末期，距峰值1-2季度）

AI服务器HBM需求（2025Q3起爆发） → 三大厂HBM产能2026全年售罄 → DRAM合约价Q1 +90-95%（已达峰值区间） → DRAM合约价Q2 +58-63%（仍高位但趋缓） → HBM吞噬23%全球DRAM晶圆，消费DRAM供给挤压 → 手机BOM成本暴涨，SoC厂削减投片10-15% → 中国OEM下修全年手机出货目标 → 智能手机均价创纪录$523，终端需求负反馈收缩 → 2026H2新产能（P&T7/M15X）陆续开出的顶信号 → LTA化（60-70% DDR5已锁定）延缓价格暴跌 → 预期2027Q1-2027H1价格松动（⚠️推测，存不确定性）

链二：AI芯片三重瓶颈传导

链三：三星代工复苏传导

TSMC 3nm涨价5-15% → 大客户评估多重代工策略 → 三星2nm良率升至~60%，接Apple/NVIDIA/Anthropic/AMD订单 → 三星非存储业务Q3亏损收窄 → Q4有望扭亏为盈 → 三星成为全球唯一HBM+代工+先进封装一体化供应商 → 三星HBM4+代工+ASIC构成"AI半导体全家桶"生态差异化
