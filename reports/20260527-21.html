1. 台积电AI产能🟢确认上行 Jensen Huang抵台锁定CoWoS产能，Vera Rubin六芯片平台进入量产爬坡。台积电CoWoS月产能从3.5万片扩张至年底12-14万片，NVDA预占超50%，台积电AI收入占比逼近33%。CoWoS仍是AI芯片最大瓶颈，代工厂议价权持续强化。

2. SK海力士存储结构升级🟢确认上行 存储行业估值逻辑正在从PB切换至PE，长期供应协议(LTA)重构商业模式。SK海力士营收₩52.6万亿(+198% YoY)，三星存储营业利润+756% YoY至₩57.2万亿。UBS上调MU目标价至$1,625，Nomura SK海力士目标价₩400万。内存短缺预期持续至2027-2028年。

4. 三星罢工供应风险🔶结构不确定性 三星电子工会威胁18天罢工，韩国总理警告每天损失$6.67亿。三星占全球DRAM供应45%，HBM供应同时服务NVDA和AMD。若罢工持续，将迫使HBM/DRAM价格进一步上行，同时加速客户多元化至SK海力士/美光。

5. 手机SoCESG承压🔶存疑 存储价格飙涨导致手机BOM成本激增，IDC预测2026年智能手机出货量-12.9%。高通Q2指引-9.7% QoQ，联发科-3% QoQ。但ASIC业务结构性对冲手机下行，手机SoC厂的AI/数据中心转型是市场重估核心逻辑。

🏢 细分领域动态

一、AI基础设施——Vera Rubin时代开启，CoWoS仍是最大瓶颈

事件： Jensen Huang 5月23日抵达台北，Computex 2026主题演讲定档6月1日11:00(GTC Taipei)。核心议程是与TSMC董事长魏哲家敲定Vera Rubin平台的CoWoS产能分配承诺。Vera Rubin是六芯片系统（Vera CPU + Rubin GPU + NVLink 6 + ConnectX-9 + BlueField-4 + Spectrum-X），每NVL72配置含36颗Vera CPU+72颗Rubin GPU、近200万个部件、约150家台湾供应商。

同时，NVDA Q1 FY2027营收$816亿(+85% YoY)，数据中心$752亿(+92% YoY)，EPS $1.87双beat。Huang预测Vera CPU打开$2000亿新TAM，2026年已预订$200亿Vera CPU独立销售。

竞争影响：

🟢 台积电 — CoWoS产能从3.5万片/月扩张至年底12-14万片（4倍），NVDA预占超50%，定价权向代工厂倾斜。台积电ADR $412.32，再创历史新高
🔶 AMD — $100亿押注台湾封装（ASE/SPIL合作），Helios平台（EPYC Venice + MI450X）H2 2026大规模部署。但Lisa Su指出HBM已成AI芯片新瓶颈，不是CoWoS
🟢 Broadcom — AI收入$84亿/季(+106% YoY)，$730亿AI积压订单，$1000亿2027年AI收入目标。Tomahawk 6(102.4Tbps)已量产出货，AI ASIC市场份额≈95%(+Marvell)
🟢 Marvell — AI ASIC营收2026年指引$110亿，Amazon Trainium+Microsoft Maia双客户持续推进

二、存储（Memory）——估值范式转移，LTA重构周期逻辑

事件： 存储行业正处于"40年来最剧烈"的结构性转变。三大核心信号：

1. LTA（长期供应协议） — Google/Microsoft/Meta与三星/SK海力士/美光签订3-5年锁量合同，部分预付定金。Server DDR5约60-70%已进入长协框架，预计2027年全行业20-30% DRAM+20% NAND通过LTA执行。Nomura/SK Securities/Macquarie集体从PB估值切换至PE估值。Nomura将SK海力士目标价从₩88万上调至₩400万。

2. 美光$1万亿里程碑 — MU突破$1万亿市值，UBS目标价从$535升至$1,625。Fab 6（弗吉尼亚）开始1α nm LPDDR4/DDR4产线，但TrendForce确认这仅是产能转移而非新增，DDR4供应将持续紧缺。HBM4爬坡速度是HBM3的2倍。

3. 三星罢工风险 — 全国三星电子工会（约2.8万人）威胁18天罢工，韩国总理警告每天损失$6.67亿。三星报告Q1存储营业利润₩57.2万亿(+756% YoY)但内部奖金分配不均触发罢工。如果罢工持续，可能推动HBM价格进一步上涨并加速AMD向SK海力士/美光多元化采购。

竞争影响：

🟢 SK海力士 — iHBM热管理方案发布（embedded cooling elements），热阻降低30%。HBM4/5推进中，营收₩52.6万亿(+198%)，营业利润率72%，HBM售罄至2027年底
🔴 三星 — 罢工+内部奖金争议+HBM落后SK海力士1-2代。Q1存储虽强但结构性劣势明显
🟢 美光 — $1万亿估值天花板打破，HBM4E 2027年量产，1-gamma节点将成为史上最大出货量的DRAM节点

三、AI ASIC——出货量增幅3倍于GPU，MediaTek成最大黑马

事件： TrendForce数据显示2026年定制AI芯片出货量将增长44.6%，是通用GPU(16.1%)的近3倍。Evercore将当前环境定义为"inference-led regime"，购买标准从"最大吞吐量"转向"每token成本/功耗/散热/TCO"。

MediaTek（联发科）结构性爆发：

Google取消Broadcom主导的TPU v9"Pumafish"项目，转由联发科主导2nm"Humufish"项目（采用HBM4e）
2026年AI ASIC营收指引从$10亿翻倍至$20亿，其中Q4单季$20亿
2027年ASIC营收指引从数十亿美元大幅上调至$70-120亿
2028年TPU营收预计$360亿（占63%总收入），CLSA目标价NT$5,922
1.4nm TPU v10"Icefish"项目已启动
OpenAI据报与联发科合作开发AI手机（2nm Dimensity 9600 + LPDDR6 + UFS 5.0），2027-2028年目标3000万台
Samsung李在镕低调访台会晤蔡力行，试图用存储产能换取2nm以下代工订单

竞争影响：

🟢 联发科 — 从手机SoC公司质变为AI平台公司。解除交易限制后直奔涨停NT$3,550，现已NT$4,640。Google TPU主导地位确定性极高
🔶 Broadcom — Google失去TPU v9项目是重大打击，但仍有OpenAI（$100亿AI积压）、Meta等客户。整体AI ASIC需求仍在高速增长
🔶 Marvell — 与Broadcom分享95%的AI ASIC市场，Trainium+Maia两线推进
🟢 Alchip（创意电子） — 2026年重回增长，3nm AI加速器项目Q2开始量产出货，预计80%营收落在下半年

四、手机SoC——存储涨价重创终端，结构下行但ASIC对冲

事件： IDC预测2026年智能手机出货量-12.9%（供应短缺驱动，非需求不足）。联发科Q1出货9700万颗(-18% YoY)，高通7100万颗(-7% YoY)。存储BOM占比从正常的~15%飙升至~30%，中国OEM（小米/OPPO/vivo）强烈抵制涨价。

Q2指引：高通-9.7% QoQ、联发科-3% QoQ，均归因于存储短缺导致的手机出货下修。

竞争影响：

🔶 高通 — 传统手机SoC定价权强，但存储涨价正在削弱其Snapdragon高端旗舰溢价。2026Q1手机SoC份额24%维持第二
🔶 联发科 — 手机SoC短期承压，但ASIC业务的结构性爆发使手机下行成为次要矛盾。市场正在用ASIC逻辑重估联发科估值
🟢 紫光展锐 — 入门级4G市场趁机扩大份额，存储涨价同样侵蚀其成本优势
🟡 苹果 — 据报DRAM议价权从买家市场转向卖家市场，苹果从"追求最优价"转为"保证供应"

🔗 传导链追踪

AI ASIC替代GPU的渗透加速链

定制AI芯片出货增长44.6%（2026，TrendForce） → GPU出货增长仅16.1%（2026） → 推断层工作负载成为AI计算主体 → 购买标准从"最大吞吐量" → "每token成本/TCO/功耗" → ASIC在推断层具有结构性优势 → Google取消Broadcom TPU v9 → 转联发科主导2nm Humufish（HBM4e） → Broadcom/联发科格局重塑 → 2027年AI ASIC TAM预计$700-800亿 → 联发科2028年TPU收入$360亿（占总收入63%）← ⚠️ CLSA预期

存储供给紧缺的全局连锁链（当前：供给结构性偏紧，LTA锁定延缓周期）

AI数据中心建设狂潮（NVDA/GOOGL/AMZN/META，2025-2027） → Server DRAM需求+40%/HBM需求+35%/NAND需求+63%（2026） → 存储库存降至历史最低3-5周 → 三星DRAM全球供应45% → 罢工威胁(18天，$6.67亿/天) → DRAM合约价Q2再涨58-63%，NAND再涨70-75% → 手机BOM中被存储占比升到~30% → IDC预测2026手机出货-12.9%（供应短缺驱动） → 联发科/高通Q2指引-3%/-9.7% → 消费电子厂商利润承压（小米/OPPO/传音） → 长期供应协议(LTA)加速推进（2026：60-70% server DDR5锁定） → 存储行业估值范式从PB → PE切换 → 新产能2027H2-2028年陆续开出（非即时缓解） → 预期紧缺至少持续至2028年（错：SK集团会长/美光均如此判断）

传导链关键观察点

最紧张的节点： 三星罢工风险——如果罢工持续超过1周，HBM供应将实质性减少，NVDA/AMD AI芯片出货将受影响，进而推动NAND/DRAM进一步上涨。同时二级存储客户（传音/小米）将面临更严重的供应挤压。

最脆弱的环节： 消费电子（PC/手机）OEM的利润传导——存储价格飙升已压缩到终端厂利润，但这些下游厂商无法快速将成本转嫁给消费者。传音在非洲市场的定价敏感性最高，是最先受损的标的。

最有结构的投资逻辑： ASIC替代GPU的推断层渗透——这是对联发科、Broadcom、Marvell的核心投资主题。Evercore的"inference-led regime"判断意味着定制芯片的结构性增长将持续多年。
